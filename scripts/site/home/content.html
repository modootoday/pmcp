Shared infrastructure should make the working model easier to understand.

Does PMCP replace my AI runtime?

No. Your native runtime makes model requests and handles its own authentication. PMCP provides discovery, shared configuration, and optional coordination tools.

Do I need mailbox, tmux, or embeddings?

Skill discovery and shared configuration do not require them. Mailbox and semantic search are optional. The optional harness and TUI need Linux, tmux, util-linux flock, and the documented Node and user-systemd setup.

Can MCP clients run the session manager?

Session execution belongs to the optional CLI host. It is separate from the MCP server execution boundary.

What is the license?

PMCP is source available under Elastic License 2.0. Read the license before redistributing or offering a hosted service.
