Two of these write the configuration for you. The rest are a line of JSON or a command, depending on where your agent keeps its servers.

One click

Those two links carry the whole server definition in their payload, so the editor opens with the form already filled in.

As a dev dependency

npm install --save-dev @modootoday/pmcp

Installing it is optional. Every configuration below runs it through npx -y @modootoday/pmcp, which works with nothing installed; adding it to the project pins the version your team gets.

Native marketplace

Install selected library instructions from the public repository without a PMCP account. Each library major is a separate plugin; registering the marketplace does not install every plugin. 

claude plugin marketplace add modootoday/pmcp
claude plugin install typescript-5@pmcp

codex plugin marketplace add modootoday/pmcp
codex plugin add typescript-5@pmcp

grok plugin marketplace add modootoday/pmcp
grok plugin install typescript-5@pmcp

Select the pmcp plugin to add the MCP bridge. Gemini can install that bridge with gemini extensions install https://github.com/modootoday/pmcp. Provider authentication and installation confirmation stay native.

Repository main also supports exporting one plugin for Gemini or Antigravity with pmcp marketplace export. That CLI command and the bundled free catalog await the next npm release; npm 0.13.1 retains its existing CLI behavior. Native formats and selected exports.

A host that spawns servers over stdio

{
  "mcpServers": {
    "pmcp": { "command": "npx", "args": ["-y", "@modootoday/pmcp"] }
  }
}

That is the shape most hosts read. The file it goes in differs by host, and the two commands below write it for you.

Claude Code

claude mcp add pmcp -- npx -y @modootoday/pmcp

VS Code, from a script

code --add-mcp '{"name":"pmcp","command":"npx","args":["-y","@modootoday/pmcp"]}'

The same thing the badge does, for setting up a workstation rather than clicking through one.

Options the server takes

--root <dir> a node_modules directory to walk, instead of discovering upwards from the working directory; repeatable
--scope <prefix> only packages whose names start with this; repeatable, and takes a comma-separated list

Both go in the args array beside pmcp. A host that passes them with no command still gets the server, because a bare spawn is what the protocol expects.

What arrives

  • Node 22 or later, or Bun 1.3 or later.
  • Runtime dependencies: @modelcontextprotocol/server, zod, semver, smol-toml and yaml. Their MIT, ISC and BSD-3-Clause notices are listed in the package's NOTICE.
  • No postinstall hook, and nothing downloaded at install time. Semantic ranking needs an optional peer you install yourself.

Optional native workspace

Share MCP settings through project configuration. The native harness and terminal workspace require Linux, tmux, util-linux flock, Node.js 22 and a working user systemd manager. The TUI requires PMCP 0.13.0 or later. Run pmcp tui doctor before creating a view. Provider credentials stay with the native tools.

Check it before you trust it. npx -y @modootoday/pmcp list prints what the server would see from this directory. Repository main includes its free catalog; --no-builtin restricts discovery to your own roots. The five-minute version.
