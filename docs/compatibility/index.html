What runs where. Other pages link here instead of repeating requirements. What does not work yet is on Known issues.

pmcp-browser and pmcp-desktopx64 and arm64, glibc 2.35 or laternot shippednot shipped

All of them need Node.js 22 or later, or Bun 1.3 or later. npm installs pmcp-pty, pmcp-tui and (on Linux) the two plugin binaries through a platform package, @modootoday/pmcp-<os>-<cpu>. PMCP_PTY_BIN and PMCP_TUI_BIN point at other builds. On Linux a user systemd manager caps each native session's memory; macOS runs sessions without that cap. The macOS binaries are unsigned; installed through npm they run as they are, since npm sets no quarantine flag.

Provider authentication, native children and vendor behavior have separate qualification scopes. An installed executable or exported manifest is not proof that every native feature works. The packed-package check, run before a release, covers actual archive installation, CLI startup, MCP and SQLite; isolated projects on a host are distinct from Docker and OS qualification.
