pmcp-sessions-and-git

Work alongside other agent sessions in a pmcp repository - read who is working and what is held with pmcp sessions status, leave pause and broadcast to the user, wait out a lease, work in a linked worktree instead of the shared main checkout, deliver commits through pmcp git deliver rather than git push, sync the main checkout and linked worktrees, and read pmcp logs to explain a hook refusal. Use when a pmcp hook refused or warned, when several agents share one repository, when asked to deliver work, or when a session reports a pause, lease or leftover edits. Not for writing pmcp.toml (set the project up first) or for repositories without pmcp hooks.
