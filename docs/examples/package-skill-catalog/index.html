package-skill-catalog

Find, check and load the right skill from a PMCP skill catalog instead of guessing, including version-appropriate instructions for installed public libraries, and install selected PMCP marketplace skills through a native runtime. Use when a task might have a dedicated skill, when the PMCP tools (skill_find, skill_catalog, skill_describe, skill_call, skill_read, skill_bundle) are available, or when a search for a skill came back empty.
