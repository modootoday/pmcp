pmcp-browser

Browse public websites from a Linux host through the pmcp-browser MCP server (navigate, snapshot, click, type, read, screenshot). Use when a task needs a web page and no desktop browser is available. Not for GUI apps (use pmcp-desktop) or for sites behind a login.
