Glossary

Back to the overview

The words pmcp's documentation and messages use, each with the page that owns it.

TermMeaning
skillA SKILL.md an agent loads when its task matches: a description that decides when, and a body with the instructions. Skills reference
catalogThe skills pmcp finds in installed packages, workspace packages and marketplaces; skill_find searches it. Getting started
marketplaceA collection of plugins that native runtimes install; pmcp ships a free public one. Skills reference
projectionThe native files pmcp project writes for each tool from pmcp.toml and .agents/; pmcp.lock records what it owns. Project configuration
hook bundleThe guards, checks and session bookkeeping [hooks] compiles and every targeted runtime runs on its tool calls. Hooks
sessionOne running agent conversation in the repository, as the hooks record it. Run several agents
shared checkoutThe repository's main checkout when linked worktrees exist; an edit left there blocks syncing it for every session.
linked worktreeA separate checkout pmcp git worktree create makes for one agent. Messages address it as worktree:<path>; desk:<path> is an older spelling that still works. Git workflow
mainlineThe branch deliveries go to: [git] mainline, else the remote's HEAD branch, else main.
deliverypmcp git deliver: replay commits onto the mainline, run the gate, push. "Being delivered" in a message means one is in progress.
gateThe test command a delivery must pass, [git.mainline.gate].
leaseA hold on a file two sessions must not change at once, such as a lockfile; the listed commands wait while a delivery holds it.
pausepmcp sessions pause: every other session's edits and mutating commands are refused until resume.
broadcastText every running session receives once, as context.
sessions mailboxAddressed messages between the sessions of one repository, pmcp sessions send. Run several agents
local mailboxMessages between actors that hold their own credentials, pmcp mailbox, across projects and hosts. Local mailbox
operatorA name, not a role: the default sender of pmcp sessions pause, broadcast and send (--by), and a mailbox actor you may register. The docs call the person "you".
runtime idHow each table names a native runtime; the ids differ between tables. Compatibility
main and workerIn a terminal workspace or harness group, the session you mainly talk to and the ones it delegates to. Terminal workspace
harness groupThe sessions one pmcp-pty daemon hosts for pmcp tui or pmcp harness, with a budget and a generation that changes when the group is replaced. Native terminal control
controlHolding the lease on a hosted session so only you type into it; program input waits until you release it.
host ([host])The long-running sessions pmcp harness host runs from pmcp.toml, once you approve the projected policy. Sessions pmcp-pty hosts
platform package@modootoday/pmcp-<os>-<cpu>, the npm package that carries the native binaries for one platform. Compatibility
