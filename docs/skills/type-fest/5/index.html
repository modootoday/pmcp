type-fest 5.x

Use type-fest v5.0.0 as a strict, type-only utility package. Covers v5 module/configuration requirements, the documented Except and Tagged APIs, and migration traps from v4.

One example from this skill

This is the skill's own text, not a summary of it. It runs: that is what verifying means here. 

import assert from 'node:assert/strict';
import type {Except} from 'type-fest';

type Foo = {
	a: number;
	b: string;
};

type FooWithoutA = Except<Foo, 'a'>;

const value: FooWithoutA = {b: '2'};
assert.deepEqual(value, {b: '2'});
