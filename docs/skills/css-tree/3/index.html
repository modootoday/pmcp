css-tree 3.x

Use css-tree 3.x to parse, traverse, transform, generate, and lex CSS ASTs. Covers the v3 AST/API changes that commonly break v2-era code.

One example from this skill

This is the skill's own text, not a summary of it. It runs: that is what verifying means here. 

import assert from 'node:assert/strict';
import { generate, parse } from 'css-tree';

const ast = parse('.example { world: "!" }');
assert.equal(generate(ast), '.example{world:"!"}');
