jsdom 30.x

Use jsdom ^30.0.0 from a plain Bun/Node script to construct and inspect DOMs and create document fragments. The documented v30 package requires Node.js ^22.22.2 || ^24.15.0 || >=26.0.0.

One example from this skill

This is the skill's own text, not a summary of it. It runs: that is what verifying means here. 

import assert from "node:assert/strict";
import { JSDOM } from "jsdom";

const dom = new JSDOM("<!DOCTYPE html><p>Hello world</p>");

assert.equal(dom.window.document.querySelector("p")?.textContent, "Hello world");
