pmcp mailbox
  Manage opt-in local peer mail and launcher credentials

  pmcp mailbox <subcommand> [options]

  Subcommands
    init      Create the project UUID and mailbox state
    actor     Register an actor and write its private credential
    rotate    Replace an actor's credential (administration)
    send      Send a message from --input as the actor
    inbox     List the actor's messages
    read      Read a message and record a receipt
    ack       Acknowledge a read message
    sessions  List attached sessions
    export    Export correspondence (administration)
    backup    Back the mailbox state up (administration)
    restore   Restore a backup (administration)

  Run pmcp mailbox <subcommand> --help for one subcommand's usage.

  Options
    --config <file>          A pmcp.toml to read instead of the nearest one.
    --state-dir <dir>        Private mailbox state directory
    --actor <id>             Registered actor ID
    --actor-file <file>      Private actor credential file
    --binding-file <file>    Private existing attachment file
    --parent-binding <file>  Live parent attachment for bounded child delegation
    --input <file>           Operation input JSON or backup source
    --output <file>          New export or backup destination
    --scope-actor <id>       Limit export to one actor's correspondence
    --operator               Explicit local administrator intent

  Examples
    pmcp mailbox init --config ./pmcp.toml
    pmcp mailbox actor --actor reviewer --actor-file /private/reviewer.actor.json
