pmcp doctor
  Ask each agent tool, through its own listing commands, whether it loads this project's assets

  pmcp doctor [--tool <name>] [--json] [--memory]

  --config <file>  A pmcp.toml to read instead of the nearest one.
  --tool <name>    Check only this tool (claude, codex, gemini, grok, antigravity, opencode). Repeatable.
  --json           Emit JSON rather than a table.
  --memory         Report native memory configuration metadata only; do not read memory bodies or check MCP connections.
