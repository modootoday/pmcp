pmcp hooks
  List compiled policies or simulate a native hook without a runtime

  pmcp hooks [<subcommand>] [options]

  Subcommands
    list    List compiled policies per runtime and event
    test    Simulate one native hook call, or run a fixtures file
    report  Summarise the guard lines in the project log

  Run pmcp hooks <subcommand> --help for one subcommand's usage.

  Options
    --config <file>         A pmcp.toml to read instead of the nearest one.
    --json                  Print the result as one JSON envelope on stdout.
    --fixtures <file>       Run these cases through the projected hook entry for every wired runtime.
    --since <when>          Report only log lines from this long ago (10m, 2h, 3d) or this ISO time.
    --switch-check <guard>  List the calls this guard found something in but let through.
    --runtime <runtime>     Native runtime to inspect.
    --event <event>         Neutral or native event name.
    --command <text>        Shell command to classify; never executed.
    --path <path>           Path for a synthetic edit.
    --tool <name>           Native tool name or shell, edit, read, other.
    --session-state <file>  JSON seed for isolated session state.

  Examples
    pmcp hooks list --runtime claude
    pmcp hooks test --runtime codex --event before_tool --command "git add -A"
