pmcp git
  Create and sync worktrees, deliver commits to the mainline, sync the main
  checkout

  pmcp git <subcommand> [options]

  Subcommands
    worktree create  Make a linked worktree on a new branch from the upstream
    worktree list    The main checkout and each linked worktree, with
                     behind/ahead
    worktree sync    Move this worktree onto the mainline when that loses
                     nothing
    deliver          Replay, gate and push commits to the mainline
    sync             Move the main checkout, or this desk, to the mainline

  Run pmcp git <subcommand> --help for one subcommand's usage.

  Options
    --json           Print the result as one JSON envelope on stdout.
    --config <file>  A pmcp.toml to read instead of the nearest one.
    --base <ref>     Start a new worktree from this ref instead of the upstream
    --during-pause   Deliver although the sessions are paused
    --no-push        Replay and gate, then stop without pushing

  Examples
    pmcp git worktree create review
    pmcp git deliver --json
