pmcp git
  Create and sync worktrees, deliver commits to the mainline, sync the main checkout

  pmcp git worktree create <alias> | worktree list | worktree sync | deliver [<commit>...] | sync

  --json           Print the documented versioned JSON schema.
  --config <file>  A pmcp.toml to read instead of the nearest one.
  --base <ref>     Start a new worktree from this ref instead of the upstream
  --during-pause   Deliver although the sessions are paused
  --no-push        Replay and gate, then stop without pushing
